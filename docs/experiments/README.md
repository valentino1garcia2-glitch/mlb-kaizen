# Experiment records

Create one short file per material experiment: `YYYY-MM-DD-topic.md`. Record the question, immutable inputs/data version, temporal split or leakage controls when relevant, command/seed, metrics, result, decision, and artifact paths. Before running a new experiment, search this directory and `docs/decisions.md` for equivalent work.

Do not overwrite prior evidence. A rerun needs a stated reason: changed inputs, changed code, corrected methodology, or explicit replication.
