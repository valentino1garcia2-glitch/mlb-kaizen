# E9 — Días de descanso point-in-time

## Pregunta

¿Los días completos sin jugar desde el último partido de cada equipo mejoran
las probabilidades frente al modelo E3+E7+E8?

## Hipótesis

Descanso desigual puede reflejar fatiga o recuperación. Es una señal disponible
en el calendario antes del inicio de un partido y no necesita fuentes externas.

## Diseño fijado antes de evaluar

- Fuente: colección normalizada local de MLB, 2022–2026.
- `rest_days = max(0, fecha_actual - fecha_último_juego - 1)` para cada equipo.
- Un juego al día siguiente, o en doble cartelera, equivale a 0 días de descanso.
- No se limita, agrupa ni transforma el valor mirando los resultados.
- Control: Poisson E3+E7+E8 sobre las mismas filas E9.
- Candidato: el mismo modelo más `home_rest_days` y `away_rest_days`.
- Selección: 2022–2024 para entrenar; 2025 para decidir.
- Test final 2026: únicamente si Brier y log loss mejoran los dos en 2025.
- Criterio de parada: si 2025 no mejora ambas métricas, documentar negativo y
  no abrir 2026 para rescatar la hipótesis.

## Salvaguardas

El último juego de un equipo se lee antes del partido actual y se actualiza
después. Las pruebas cubren cálculo de descanso, juegos consecutivos, futuro y
timestamps.

## Resultado

### FACT

E9 usa las mismas 10,696 filas que E8. Para la validación de 2025 se entrenó
con 6,470 filas (2022–2024) y se evaluó con 2,171 filas.

| Modelo | Brier | Log loss | MAE local | MAE visitante |
| --- | ---: | ---: | ---: | ---: |
| Control E3+E7+E8, mismas filas | **0.244775** | **0.682519** | 2.392903 | 2.616148 |
| E9 + días de descanso | 0.244870 | 0.682720 | **2.392464** | **2.615227** |

### INTERPRETACIÓN

Aunque el error medio de carreras bajó marginalmente, Brier y log loss
empeoraron. El criterio pre-registrado exigía que ambas métricas de
probabilidad mejoraran; no ocurrió.

### DECISIÓN

**DISCARD para el modelo activo.** No se evaluó 2026, porque hacerlo después
de fallar 2025 sería usar el test final para rescatar una hipótesis rechazada.
El código y fórmula quedan trazables para un rediseño futuro, no como señal
demostrada.
