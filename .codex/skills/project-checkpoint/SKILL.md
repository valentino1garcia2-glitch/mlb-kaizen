# Project checkpoint

Apply the closure sequence proportionally: focused tests, fuller suite when warranted, `STATUS.md`, `.agent/checkpoint.json`, a small commit, remote push, then clean `git status`. Do not claim a push, tag, or backup happened without checking it. If a step is unavailable, leave the state honest and name the exact next action.
