# Project handoff

Write `HANDOFF.md` from current Git and test evidence: objective, stable baseline, working-tree condition, remote/backup state, risks, and one actionable resumption path. Update `STATUS.md` and checkpoint if the handoff closes a stable block. Never place secrets, credentials, or unverified claims in handoff materials.
