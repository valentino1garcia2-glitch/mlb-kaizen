# Experiment runner

Search `docs/experiments/` and decisions before running work. State the question, inputs/data version, controls, split/leakage safeguards where relevant, command, seed, metrics, and stopping criterion. Store outcomes in a new dated record; do not overwrite prior evidence. Change code, data, or conclusions only within the explicit experiment scope.
